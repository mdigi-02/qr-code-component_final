This my implementation of [__FrontEnd Mentor__](https://www.frontendmentor.io/)'s [_QR Code Component_](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) challenge.\
It is a simple, static HTML page styled with CSS, with a QR code image as the central element.

Key concepts:

* Basic HTML & CSS syntax
* The CSS box model
  - Flexbox
* CSS position and `position: absolute`
